# React Movies

Movie search application built with React, TypeScript, Vite, and the TMDB API.

## Setup

1. Create a `.env.local` file from `.env.example`.
2. Set `VITE_TMDB_TOKEN` to your TMDB API read access token.
3. Install dependencies with `npm install`.
4. Start the development server with `npm run dev`.

Keep your token out of committed source files.

## Commands

- `npm run dev` starts the Vite development server.
- `npm run build` type-checks and creates a production build.
- `npm run lint` runs ESLint.
- `npm run preview` serves the production build locally.
